# Repository scope

This repository contains only the Vohk One Flutter application.

- Keep the Flutter project at the repository root.
- Do not add backend, Angular, deployment, generated build, research, or temporary files.
- Preserve the Dart package name `vohk_app` unless a dedicated migration is approved.
- Never commit `.env`, signing keys, service-account credentials, or generated build output.
- Before proposing a change, run the relevant Flutter analyzer and tests.
